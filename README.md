# 大模型免费渠道全景表 | Free LLM Channels Tracker

> 国内外可零成本使用大模型与编程 Agent 的渠道台账：官方 API 免费层、云平台赠金、编程工具、学生福利与限时活动——**每日自动巡查更新，每条带来源链接与核实日期**。

**在线使用**：`https://lm7644.github.io/free-llm-tracker/` （GitHub Pages，手机可"添加到主屏幕"）

## 这是什么

一张持续维护的表格，回答一个问题：**现在有哪些渠道能零成本用上大模型？**

- **80 条渠道**，分九类：官方 API 免费层 / 云平台赠金 / 编程 Agent·CLI·IDE / 学生教育福利 / 聊天客户端 / 限时活动 / 免费算力 / 公益中转（不推荐）/ 已停用历史区
- 每条含：免费内容、代表模型、**额度性质**（永久 / 每日 / 每月 / 一次性 / 限时 / 学生）、限额、使用方式、到期时间、准入门槛、风险备注、**可信度分级**（官方 / 多方 / 第三方 / 未核实）、**最后核实日期**、来源链接
- 顶部「限时窗口」聚焦有截止日的活额度；已停用渠道隔离进历史区防踩坑
- 单文件 HTML、零外部依赖、离线可用；桌面 / 移动自适应，支持 PWA 添加到主屏幕

## 为什么可信

「免费」分三种完全不同的性质，混在一起就是误导：**永久免费**（常限速）、**周期刷新**（每日/每月）、**一次性赠金**（有有效期）。本表逐条区分，并给每行标注：

- **可信度**：官方（定价页直核）＞ 多方（≥2 独立来源一致）＞ 第三方（单一来源）＞ 未核实（仅传闻）
- **最后核实日期**：过期信息不会冒充现势信息——已失效渠道（如 GitHub Models、智谱高校计划）全部移入历史区留痕

## 自动更新机制

仓库内置监控管道（`monitor/`，每天 08:00 北京时间由 GitHub Actions 运行）：

1. **页面 diff**：13 个官方定价/活动页的行级对比，变更即记录（`heartbeat.log` / `reports/`）
2. **搜狗公众号关键词检索**：轮换关键词抓羊毛博主动态（免费）
3. **Tavily 广域发现**：英文/聚合来源的新渠道发现（免费额度内）
4. **极致了指定账号监控**：可选付费层，监控莫理、狗哥玩ai 等羊毛博主账号
5. **博查中文检索**：周六门闩 + 预算节奏制（1000 次/3 个月）

发现的变化写入 `monitor/reports/日期.md` 与 `feed.xml`（RSS）。

## 本地使用

直接下载 `大模型免费渠道全景表.html` 双击打开——**单文件、零外部依赖、完全离线可用**。数据编辑改 `免费渠道种子表.csv` 或 `app_template.html` 内嵌 DATA（单一数据源为模板内嵌数组，CSV 由其导出）。
